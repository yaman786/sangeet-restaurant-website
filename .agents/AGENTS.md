
## Pre-Deployment Rule
Before committing and pushing ANY code to the production main branch, the agent MUST execute the `./scripts/pre_deploy.sh` script and verify that it passes 100%. If it fails, the agent MUST fix the errors before pushing. This guarantees zero downtime for the restaurant business.

## Graphify Architecture First
Whenever you are asked to implement a large feature (like the Admin Dashboard), refactor code, or analyze the architecture, you MUST NOT blindly read raw files. Instead, you must first read the `GRAPH_REPORT.md` or query `graph.json` generated by Graphify to understand the project structure and dependencies. This saves ~70x tokens and context length. If the graph is missing or outdated, you must run `uvx --from graphifyy graphify` to generate it before writing or analyzing any code.

## Automated Testing Rule (Playwright)
Whenever verifying user flows, frontend UI features, or end-to-end functionality, the agent MUST write or execute Playwright test scripts in `tests/` using `npx playwright test` instead of relying on interactive browser subagents. Playwright is our mandatory, production-grade automated E2E testing framework.
